# CrossPuck Audio 0.6.0

This fork is now an audio-only macOS menu bar utility. Controller/HID support,
Steam bridge and guest DLL installation, bottle editing, profiling tools,
Sparkle and all update checks have been removed. Building requires only the
macOS Rust toolchain and Apple's Command Line Tools.

Audio output following, sleep/wake recovery, direct Wine and generated Menu
Helper discovery, safe route cleanup and read-only diagnostics are retained.
The menu supports English, Simplified Chinese and Japanese with a persistent
language selection. Monitoring and rerouting are explicitly distinguished.
The menu no longer uses a periodic UI refresh timer.

Requires macOS 14.2 or later. Existing FollowAudioOutput preferences and the app
bundle identifier are preserved. Local-signature changes may require renewed
System Audio Recording permission. Input Monitoring is no longer needed.
