# Crossover Sleep-Audio-fix v1.0

First DMG release of the audio-only utility. The application version is 1.0.0.
The download is for Apple Silicon (M-series) Macs running macOS 14.2 or later.

## What it fixes

After waking from sleep, a CrossOver program may keep playing through the Mac's
built-in speakers even after macOS has selected an external output. This tool
follows the currently selected macOS output and rebuilds audio forwarding after
wake when needed. Programs launched through CrossOver-generated desktop
shortcuts are recognized too. Parts of the implementation are inspired by
CrossPuck.

## Install

1. Open the DMG and drag Crossover Sleep-Audio-fix.app into Applications.
2. Quit an older CrossPuck or Crossover Sleep-Audio-fix instance, then open the app.
3. Allow System Audio Recording if prompted and enable Follow macOS Audio Output.
4. Select your preferred output in macOS Sound settings.

The speaker menu supports Chinese, Japanese and English. Monitoring is normal
when programs already use the correct output; Rerouting means audio is being
forwarded from another device. Audio stays in memory and is never saved or
uploaded. Controller support, Windows drivers and update checks are absent.

## Package notes

The app is locally signed (ad hoc) and has not been notarized by Apple. macOS may
require first-launch approval. The DMG includes the app, an Applications shortcut,
the three-language README and the license. SHA256SUMS.txt verifies the download.

The app follows the system's output selection; it does not choose a particular
speaker or make a disconnected audio device available. Device and application
compatibility can vary. Use the Issues form if a problem remains.
